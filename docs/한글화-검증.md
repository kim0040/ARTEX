# 한국어 학습판 작업 및 검증 기록

확인일: 2026-10-07. 기존 `ac01776` 작업 사본의 한글화에 이어 수정했습니다. 이 기록은 로컬 작업 사본의 증거이며 GitHub에 공개된 릴리스를 뜻하지 않습니다.

## 완료한 범위

- 표시 이름은 **ARTEX 한국어 학습판**, 성격은 **비공식 한국어 포크**로 명시했습니다. 실행 파일 `artex`, 로그인 이름 `ARTEX`, API·도구 식별자는 호환성을 위해 유지했습니다.
- 화면 메뉴, 버튼, 확인창, 오류 안내, 접근성 이름, 한국어 날짜·달력, 보고서의 고정 문구를 정리했습니다. 내장 도구는 화면에서 한국어 요약을 보여 주고 모델에 전달하는 설명은 보존합니다.
- 한글 `[모델]`과 기존 `[模型]` 가로채기 기록을 함께 처리하고, 스킬 중복 업로드는 번역된 문장 대신 HTTP 409로 판별하도록 고쳤습니다.
- 초보자 길잡이의 파일 읽는 순서·용어·실행 흐름과 코드 주석을 보강했습니다. 저장소 관리와 작업 엔진의 소유 관계, 종료·삭제·JWT 키 보관 설명을 코드와 맞췄습니다.
- 원 AGPL·MIT 저작권 및 라이선스, 업스트림 이용 안내 원문을 보존했습니다. 출처, 소스 제공, 외부 전송·개인정보, 보증 부인과 배제할 수 없는 책임을 로그인·소개 화면과 문서에 표시했습니다.
- 포크의 설치·업데이트 경로를 정리하고 ZIP에 대응 소스 `SOURCE.tar.gz`와 고지를 넣도록 했습니다. 한국어 문구 검사와 관련 회귀 검사를 CI 설정에 추가했습니다.
- README의 화면 예시는 한국어 샘플 화면으로 다시 촬영했습니다. 샘플 모드는 실제 검사나 외부 알림을 실행하지 않는다는 표시를 추가했습니다.

## 그대로 표시하는 원문

사용자 입력·과거 기록·모델 출력·원문 증거·명령·URL·모델 이름·API 키 이름·도구 식별자·사용자 정의 및 원격 도구 설명은 임의로 번역하지 않습니다. `skills/`와 모델용 절차·JSON Schema도 보존합니다. 모든 출력이 한국어가 된다는 보장은 아니며, 제품이 제공하는 고정 안내를 한국어로 읽을 수 있도록 한 작업입니다.

## 공개 배포 전에 남은 확인

1. 설치되지 않은 플랫폼 선택 의존성과 고지 파일이 없는 의존성을 실제 배포물 기준으로 확인합니다. 현재 수집 기록의 미확인 49개는 npm 46개(플랫폼 선택 항목 30개 포함), Go 3개입니다. 이것은 49개 모두 배포물에 들어간다거나 사용이 금지됐다는 판단이 아닙니다.
2. 실제 실행 버전과 동일한 소스·빌드 자료 및 의존성 고지를 공개하고 소스 링크를 확인합니다. 이 문서의 검증은 커밋·푸시 전 로컬 작업 사본에서 수행했습니다. 소스 푸시와 실행 파일의 공개 릴리스 배포는 별도 단계입니다.
3. Docker로 배포할 경우 이미지 빌드·초기 설정·재시작·데이터 및 키 보관을 실제 환경에서 확인합니다. 다른 OS의 실행 파일 역시 해당 OS에서 확인합니다.
4. 외부 모델 실행 검증이 필요한 경우 업스트림 이용 안내와 허용 범위를 지키는 격리 샘플 환경에서 별도로 진행합니다.
